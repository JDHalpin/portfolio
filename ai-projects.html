Experiments, tools, and products built at the intersection of design and AI. These projects explore how AI can extend UX workflows, automate design-to-development handoff, and create new interaction paradigms.

Drift

Drift

A native mobile app for adults with ADHD on stimulant medication. Rooted in a March 2026 JNeurosci study identifying local sleep events as the neurological mechanism behind attention lapses. Built in React Native / Expo with a pharmacokinetic curve visualization, live drift-risk scoring, and shame-aware interaction patterns for tracking focus without triggering avoidance.

Figma Design Token Sync Tool

A UX-engineered automation that extracts design tokens directly from the Figma API via Model Context Protocol (MCP) and syncs them into a codebase — eliminating manual token transcription and the drift that comes with it.

Built in Claude Code using the Figma MCP server, the tool reads variable collections (colors, spacing, typography) and writes them to a structured CSS/JSON token file. Changes in Figma propagate to the repo with a single command — no plugin, no third-party sync service.

This was both a practical tool for my own workflow and a proof of concept for AI-augmented design-to-development handoff at the token layer.
