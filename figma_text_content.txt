“Copy selection”
Variants themselves should not be inside an Auto Layout container unless there’s a specific reason.
Only the child components (Default, Hover, Active) should have Auto Layout.
👉 Fix:
Select the Nav parent (the dashed purple frame).
Press Shift + A once to remove auto layout.
Set:
Width: Hug
Height: Hug
Padding: 0
Gap: 0
The parent should simply act as a variant container — not a layout frame.

Information Architecture
Bad habit identified: Right-click menus in Figma often give you an option, but not always the right option. The purple variant bar's + icon is the canonical way to add variants.
Other common destructive patterns to watch for:
Duplicating (Cmd+D) instead of creating instances
Using "Detach instance" instead of overriding properties
Adding Auto Layout to text instead of wrapping text in a frame first
Using absolute positioning instead of Auto Layout constraints
